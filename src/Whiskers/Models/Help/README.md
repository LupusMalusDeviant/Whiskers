# Models/Help

The shape of the in-app user handbook rendered by the Help page. The content lives in
[`Services/Help`](../../Services/Help/) (`HelpContentService` for German, `HelpContentEn` for English).

| File | What |
|---|---|
| `HelpModels.cs` | `HelpChapter` (a top-level chapter), `HelpSection` (heading, Markdown prose, optional figure) and `HelpFigure`. |
