# Whiskers 1.0.1

A security and stability release. A full review of 1.0.0 reproduced 98 findings, most with a failing test. The
security fixes and the crash fixes ship in 1.0.1; the rest is planned for 1.1.0. Contract 0017
(`docs/contracts/0017-release-1-0-1-security-fixes.md`) defines the security fixes.

## Security

- **Approval requests always reach the channels.** A second request inside the throttle window is no longer dropped.
- **mTLS.** The host's CSR is checked and re-encoded before it reaches the CA host, and every SAN is counted.
- **Agent chat and CSP.** Model output is rendered with an explicit Markdown pipeline and a stricter sanitizer. The
  CSP sets `script-src 'self'`, and no inline script or `eval` interop is left.
- **Compose.** `use_api_socket` counts as a Docker-socket mount, and a privileged hook needs approval.
- **Whitelist.** The seeded local admin and new local accounts can sign in while the OAuth whitelist is enabled.
- **Redaction.** Every sink column is redacted or exempt with a reason, and an `Authorization` value is redacted
  whole. Container env and the UI share one masking rule.
- **Guardrails.** `execute_command` reads mount sources, quoting, braces and globs as the shell does before it allows
  a command near the control plane.

## Fixes

- The telemetry compose files need `TS_IP` and no longer bind to every interface.
- A failed container update or rollback restores the previous container.
- No Python is left in the project: onboarding, borg-fleet and tailnet-guard use `sh`, `jq` and `sqlite3`.
- Tailscale starts when `VPN_HOSTNAME` is empty.
- The database tool reads PostgreSQL, MySQL/MariaDB and Redis output correctly.
- Restores replace the database the app actually opens; volume backups clean up after themselves.
- Errors in the UI no longer end the Blazor connection.

The full list is in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrading from 1.0.0

Read **Upgrading from 1.0.0** in [CHANGELOG.md](../../CHANGELOG.md) before you update. In short:

1. With the OAuth whitelist enabled, add `WHISKERS_ADMIN_EMAIL` to it by hand.
2. Rotate the Basic credentials that 1.0.0 stored or logged as `Authorization=*** <credential>`.
3. In the UI, `PWD`-like environment variables are now masked.
4. borg-fleet: install `jq` on the Whiskers host and `sqlite3` on each fleet host, then run `borg-enroll` again.
5. Install `jq` wherever tailnet-guard runs.
6. A reverse proxy that injects inline scripts is blocked by the new CSP.

INV-58 still ships at ⚠️ under the accepted exception RG-1: it holds per host only after that host's migration (see
`docs/operations/per-host-mtls-migration.md`).

## Install

```bash
VER=1.0.1
curl -fsSLO "https://github.com/LupusMalusDeviant/Whiskers/releases/download/v${VER}/install.sh"
curl -fsSLO "https://github.com/LupusMalusDeviant/Whiskers/releases/download/v${VER}/checksums.txt"
sha256sum --check --ignore-missing checksums.txt && bash install.sh
```

The image `ghcr.io/lupusmalusdeviant/whiskers:1.0.1` is built for amd64 and arm64. It is Trivy-gated, has an SBOM and
provenance, and carries a keyless cosign signature. See `docs/installation.md` for the signature check and the other
ways to install.
